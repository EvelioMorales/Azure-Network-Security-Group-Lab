# Security and privacy notes

The images in this repository are protected copies prepared for public documentation. Account names, email addresses, user principal names, tenant details, subscription IDs, and unrelated resource names were removed before publication.

The visible address `10.0.0.0/32` is a private RFC 1918 lab address, not a public internet address or credential.

Before adding future screenshots, inspect the portal header, URLs, breadcrumbs, resource properties, activity logs, error messages, IP addresses, tenant information, and subscription details. Redact sensitive data before committing the image.

Never attach this lab NSG to a production subnet or network interface without an approved change and connectivity review.
